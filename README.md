# 商店跳过（ShopSkip）

在对局中自动跳过已经没有合适购买选项的商店，减少等待时间，不会帮你自动购买道具。

## 功能说明

- **卡牌商店**：仍有商品但全部买不起时，自动使用原版「离开」按钮。价格为 **0 星币** 的卡牌也算可以买，不会被误跳过。
- **商品已售罄**：卡牌都买完后，如果已无法转账（例如剩余星币不足 5 个，或者转账机会已用），也会自动离开；仍然可以给队友转账时会保留界面。
- **ATM 转账**：完成一次转账后，等待游戏发来更新的卡牌报价和可用星币，再决定是否自动离开；若还有买得起的卡牌，则不会跳过。无需提前保存可能过期的卡牌价格。
- **筹码商店、怪奇糖果机、建筑商店**：始终尝试在打开窗口前判断是否能买得起；如果不能安装实验拦截，窗口将正常显示。

## 使用与兼容性

安装 CesiumLoader 后，将编译好的 `ShopSkip.dll` 和 `ShopSkip.json` 放入 `AstralParty_ModLoader/mods/ShopSkip/`，并在相同目录放入兼容的 `0Harmony.dll`。修改 DLL 后请完全重启游戏。

卡牌商店及 ATM 保持原有的自动离开功能。筹码商店、怪奇糖果机、建筑商店则改为**始终尝试提前拦截**，不再需要启用文件，也不再限制单人模式。为便于观察实验结果，原先针对这三个商店的窗口内自动取消已持续暂停；**如果 Harmony 加载或补丁失败，原版购买窗口会照常打开，不会自动取消**。

实验仅针对本地玩家的有效操作：只有服务端报价为正数、价格高于星币余额时才尝试发送原版取消请求并跳过窗口。0 星币免费商品、报价未知或不是本地玩家的操作都保留原版流程。

## 实验日志与排查

启动后会在日志看到 `[ShopSkip.EarlyTest] 开始尝试安装`，这说明确实进入了安装流程；如果没有这条信息，应先检查新版 ShopSkip 是否加载成功。

看到「已向 Harmony 注册」**不代表**拦截已经生效。只有实际触发商店时出现「已进入前置 Prefix」，才说明方法补丁真正执行。出现「提前跳过」则说明原版取消请求已发出。

本次移除了 Mod 代码中的 `Assembly.GetType` 调用，改用程序集限定名称查找 Harmony 类型，尝试规避 HybridCLR 中的 `MethodNotFind System.Reflection.Assembly::GetType`。但如果 `Type.GetType`、程序集动态加载方法或 Harmony 内部依赖的 AOT 方法也被裁剪，仍可能失败；此时应查看完整日志，不能据此认为拦截成功。

安装只在每个场景尝试一次，不会每帧重复执行。原有卡牌商店与 ATM 功能不受实验安装结果影响。

**注意：**实验现在也会在多人模式下尝试拦截，尚未完成实际游戏兼容性验证，可能出现商店操作异常。建议先在离线或受控环境测试，确认稳定后再考虑其他场景。要彻底停用实验，请恢复上一版 Mod 或卸载本 Mod。
